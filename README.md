
# CleenFleet 🚛
### Track the Truck. Keep Sri Lanka Clean.

CleenFleet is a smart waste collection and garbage truck tracking system designed to improve waste collection services in Sri Lanka.

Our goal is to help residents know when garbage collection trucks are expected to arrive, reduce uncertainty around collection schedules, and improve communication between residents and waste collection authorities.

## 🌍 Project Overview

In many communities, residents do not receive reliable information about garbage collection times. This creates inconvenience, missed collections, and difficulties in managing household waste.

CleenFleet aims to address this problem through a digital platform that connects residents, garbage truck drivers, and waste management administrators.

**Initial Target Area:** Colombo, Sri Lanka

## 🎯 Problem Statement

Garbage truck arrival times are unpredictable, and residents often do not know when their garbage will be collected.

This lack of communication makes waste disposal difficult and can contribute to poor waste management practices.

## 💡 Proposed Solution

CleenFleet proposes a smart platform with truck location tracking, estimated arrival times, collection schedules, and communication features.

The platform is designed around three main user groups:

- Residents
- Garbage truck drivers
- Waste management administrators

## ✨ Key Features

### 1. Live Garbage Truck Tracking
- View garbage truck locations on a map.
- Track assigned collection routes.
- Display the last location update.

### 2. Estimated Time of Arrival (ETA)
- Show the estimated arrival time of collection trucks.
- Help residents prepare their waste before collection.

### 3. Collection Schedules
- View collection dates and times.
- Receive information about upcoming collections.

### 4. Driver Interface
- Allow drivers to share their location with permission.
- View assigned collection routes.
- Update collection progress.

### 5. Admin Dashboard
- Manage garbage trucks and driver information.
- Manage collection schedules.
- Monitor collection activities.

### 6. Complaints and Missed Collection Reports
- Report missed garbage collections.
- Submit complaints or service-related issues.
- Allow administrators to review reports.

## 🏗️ System Architecture

The proposed system consists of:

1. Resident Interface – Access schedules, truck locations and reporting features.
2. Driver Interface – Share location and update collection progress.
3. Admin Dashboard – Manage trucks, drivers, schedules and reports.
4. Backend Server – Process requests and manage system data.
5. Database – Store user, truck, schedule and complaint information.

## 📍 Initial Implementation Scope

- Initial target area: Colombo, Sri Lanka.
- Focus: Garbage truck tracking and collection-time awareness.
- Platform: Web-based prototype.
- Location tracking: GPS-based tracking is proposed, subject to driver consent and operational permission.

**Prototype note:** During early development, simulated truck locations may be used for demonstration. Simulated locations will be clearly identified and will not be presented as real-time GPS data.
